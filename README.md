# 経費レシート台帳 (Tax Receipt Ledger)

レシート画像と経費情報をブラウザ内に保存し、確定申告向けのExcel台帳を作るローカル優先Webアプリです。

## 主な機能
- レシート画像の保存（IndexedDB）
- 任意OCR補助（Tesseract.js。初回通信が必要）
- 日付・支払先・金額・用途・勘定科目・所得区分の管理
- 事業利用割合から経費計上額を自動計算
- 要確認フラグ
- 科目別・月別集計
- 外部ライブラリ不要の `.xlsx` 生成
- CSV出力
- 画像込みJSONバックアップ / 復元
- PWA / `manual.html`

## GitHub Pages
リポジトリのルートにこのフォルダの中身をそのまま配置し、GitHub Pagesを main / root から公開してください。

## 税務上の注意
本アプリは証憑整理と集計を支援するツールで、必要経費該当性や勘定科目の税務判断を確定するものではありません。
