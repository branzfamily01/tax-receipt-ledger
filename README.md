# 経費レシート台帳 (Tax Receipt Ledger)

レシート画像と経費情報をブラウザ内に保存し、確定申告向けのExcel台帳を作るローカル優先Webアプリです。vFlat Scanなどで作った複数ページPDFも、1ページずつレシート候補へ分解してまとめて登録できます。

## 主な機能

- レシート画像の保存（IndexedDB）
- vFlat PDF一括取り込み（1ページ＝1レシート）
- PDFページをJPEGへ自動分解
- OCR補助（Tesseract.js。初回通信が必要）
- PDF各ページのOCR連続処理
- 日付・支払先・金額・用途・勘定科目・所得区分の管理
- 事業利用割合から経費計上額を自動計算
- 一括取り込みデータは必ず「要確認」で登録
- 科目別・月別集計
- 外部Excelライブラリ不要の `.xlsx` 生成
- CSV出力
- 画像込みJSONバックアップ / 復元
- PWA / `manual.html`

## vFlat PDFのおすすめ運用

1. vFlat Scanでレシートを撮影します。
2. 1ページに1枚のレシートになるようPDFを作ります。
3. アプリの「📄 vFlat PDFを一括取り込み」を開きます。
4. PDFを選び、必要なら所得区分・勘定科目・事業利用割合などの初期値を設定します。
5. 「ページを分解して登録候補にする」を押します。
6. 一覧に追加された「要確認」の各レシートを確認・修正します。

PDF.jsとOCRエンジンは初回利用時にCDNから読み込みます。登録データと画像はブラウザ内に保存されます。

## 税務上の注意

本アプリは証憑整理と集計を支援するツールで、必要経費該当性や勘定科目の税務判断を確定するものではありません。
